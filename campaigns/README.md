# campaigns

Une suite de scénarios à rejouer, pour toutes les méthodes à la fois.

Une campagne est un fichier qui nomme les scénarios, le nombre d'épisodes et les
graines, plus le relevé des métriques qui en sort. C'est ce qui se rejoue quand
on veut comparer une méthode à une autre sur les mêmes situations.

Le dossier est vide pour l'instant : l'architecture d'abord, les campagnes
ensuite. Le format retenu sera celui que `robotsnap benchmark` sait déjà lire,
pour qu'une campagne décrite ici se rejoue avec l'outil du cœur plutôt qu'avec
un format de plus.
